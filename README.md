
# AI Chat Assistant 🤖

## About the Project
An AI-powered chatbot built using Python, Streamlit, and Ollama.

It allows users to ask questions and receive AI-generated answers.

## Technologies Used
- Python
- Streamlit
- Ollama
- Llama 3.2 (1B)

## Features
- Interactive chat interface
- AI-generated responses
- Chat history
- Clear chat option
- Runs locally without Hugging Face API credits

## Installation

Install the required packages:

pip install -r requirements.txt

Download the AI model:

ollama pull llama3.2:1b

Run the application:

streamlit run app.py
